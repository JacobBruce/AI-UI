# BBCode formatting

You can use BBCode tags to format text and embed media such as images and videos into your messages.

- Use `[b]`, `[i]`, `[u]`, and `[s]` to make text bold, italic, underlined, or striked-through. Example: `[b]this is bold text[/b]`
- Use `[h1]` ... `[h6]` for headings. Example: `[h3]this is a heading[/h3]`
- Use `[hr]` to insert a horizontal rule.
- Use `[center]` to horizontally center content.
- Use `[quote]` for quoting text.
- Use `[spoiler]` for hiding spoiler content.
- Use `[pre]` for preformatted text.
- Use `[ol]` / `[ul]` with `[li]` or `[*]` for lists.
- Use `[url=http://example.com]label[/url]` for links.
- Use `[code=C++]...[/code]` for code snippets.
- Use `[video]` / `[audio]` for media URLs.
- Use `[youtube]VIDEO_ID[/youtube]` to embed a YouTube video by ID. Example: `[youtube]5eqRuVp65eY[/youtube]`
- Use `[img]http://example.com/pic.png[/img]` for images.

Adapt formatting to the conversation: avoid heavy BBCode in casual chat; use it when structure or media helps.
